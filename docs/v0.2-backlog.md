## E. 明确不做（防止反复讨论）

| 项 | 理由 |
| --- | --- |
| 常驻 daemon / `spawn` | FR-16 非目标：分发器**只推不跑**；保活只在进程池层 |
| LLM 参与确定性判定（就绪/依赖/波次） | 非目标：确定性逻辑不给 LLM 生成 |
| 多机分布式调度 | 非目标（本期） |
| 替代 Airflow / Temporal 的通用性 | 非目标 |
| `phase → stage`（C2） | mgt 的 phase 是**排期批次**，disflow 的 stage 是**流程位置**；强映射造出假语义 |
| 把 `done` 当业务词针脚 | 它既是机制终态（`core.TERMINAL`）又是视图列取值，**不可判定**，已登记在 `design.md` §9.1 |
