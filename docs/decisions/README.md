# 决策记录（ADR）

**一个决定一篇，写入即冻结。** 现状契约在 `docs/design.md`；这里只放「**为什么**这么定」的
历史 —— 让 `design.md` 只留现状（找「现在是什么」不用翻过「以前试过什么」）。

## 规矩

- 编号 `NNNN-短名.md`，**只增不改**；决定变了 → 新开一篇，在顶部 `Supersedes` 指回旧篇。
- 每篇四段：**Status / Context / Decision / Consequences**。
- 勘误也只能**追加** `## 后续`，不改原文（记录当时认知）。
- 新篇建好**必须登记进 `docs/INDEX.md`**（否则 `tests/test_docs_index.py` 红）。
