# 0002 看板 v9：默认只列运行中+待完成

- **Status**：Active（行为已并入 `docs/design.md` §6 的布局判据）
- **Date**：2026-10-11

## Context

看板首版把**全部状态**（含 `✓ 完成` / `— 跳过` / `✗ 失败`）平铺出来，空列也照铺；
用户反馈「显示太多、已完成不必看」，且要求「树和看板是 1:1 关系」「清晰干净」。

## Decision

- `board` 默认 `active_only=True`（只列**运行中 + 待完成**）＋**空列不铺版面**；但**事实不丢**
  —— 表头报 `══ 看板 <tree> ══ <树目标>` / `列 <stage> d/t · …` / `状态 <组> n · …`。
- `--all` 展开终态、`--all-columns` 铺空列、`--json` **恒为全量事实**（全列 × 全状态，
  不受这两个开关影响）。
- root 容器行只给 `◦ root`（树目标在表头，不重复同一段长文本）。
- 运行视图：默认只显示**有活的树**（`has_active_work`，一棵都没有时每棵一行摘要）；
  `--tree <slug>` 指定、`--all-boards` 不筛 —— **树 : 看板 = 1:1**，不把多棵树叠成一屏。

## Consequences

- 确立了**「默认视图可为可读性裁剪，机器态（`--json`）恒为全量事实」**这条通用判据
  （v8 的「终态行不打 goal」是它的前身）。
- 「树 : 看板 = 1:1」进 FR-22（多棵树作用域隔离），跨树依赖降级为 `awaits` 显式完成信号（FR-23）。
